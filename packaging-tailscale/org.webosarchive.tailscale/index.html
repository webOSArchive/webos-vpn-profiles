Tailscale for webOS

This app does nothing by itself, it adds Tailscale to the webOS VPN Settings app...

1 · GET AN AUTH KEY

  1. In the Tailscale admin console: Settings → Keys → Generate auth key. Leave it non‑ephemeral; reusable is handy.
  2. Get the key to your TouchPad. You can do any of the following:
    • Save it to /media/internal/tailscale‑authkey.txt and leave Auth key empty in step 2
    • E‑mail it to the TouchPad and paste it in
    • Type it in precisely

2 · ADD IT IN SETTINGS → VPN

  1. Add Profile → Type Tailscale.
  2. Server: type anything, e.g. tailscale — webOS requires it, Tailscale ignores it.
  3. Next → enter the Auth key (or leave blank if you saved the file), then Save & Connect.

Headscale? Put its URL in the Login server field.

3 · OPTIONS

  1. Exit node — a node name or 100.x address to send all traffic through it.
  2. Accept subnet routes — reach LANs behind your subnet routers.
  3. Use Tailscale DNS — MagicDNS, and lookups go through the tunnel so private names work on hotel Wi‑Fi.
